# ClinicalTrials.gov (clinical-trials-gov)

ClinicalTrials.gov is the U.S. National Institutes of Health (NIH) registry and results database of publicly and privately supported clinical studies of human participants conducted around the world. Operated by the National Library of Medicine (NLM), it provides a modern REST API (data-api v2) returning studies, metadata, search areas, and statistics in JSON, with no authentication required.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/clinical-trials-gov/refs/heads/main/apis.yml)

## APIs

### ClinicalTrials.gov Data API v2
The modern public REST interface to the NIH clinical-studies registry, returning JSON.

**Base URL:** `https://clinicaltrials.gov/api/v2`

**Human URL:** [https://clinicaltrials.gov/data-api/api](https://clinicaltrials.gov/data-api/api)

### ClinicalTrials.gov Classic API
The legacy ClinicalTrials.gov interface preceding the Data API v2, retained for backward compatibility.

**Human URL:** [https://clinicaltrials.gov/data-api/api](https://clinicaltrials.gov/data-api/api)

### ClinicalTrials.gov Bulk Downloads
Bulk CSV and JSON downloads of the full study registry.

**Human URL:** [https://clinicaltrials.gov/data-api/about-api/csv-download](https://clinicaltrials.gov/data-api/about-api/csv-download)

### AACT Database
A daily-refreshed SQL-friendly mirror of ClinicalTrials.gov maintained by CTTI at Duke.

**Human URL:** [https://aact.ctti-clinicaltrials.org/](https://aact.ctti-clinicaltrials.org/)
